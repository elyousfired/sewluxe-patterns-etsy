# Etsy SEO for a SewLuxePatterns listing

Reply in the user's own language, short. Listing text (title, tags, description) in English, each in its own code block, ready to paste.

The SEO is built from REAL data in two rounds. Never finish the final SEO from guesses alone.

## Inputs
- The garment: booklet PDF (preferred), or sketch + pattern specs. Take every fact from it: garment type, features, sizes, button count, closure (zipper length per size), skill level, fabrics, fabric requirements, video guide topics.
- The listing cover image if he shares it: check that its claims (skill level, sizes, features) match the booklet.
- The user's data (round 2): Etsy search-bar suggestions, Marketplace Insights results (searches + listings, last 30 days), eRank tags of a competitor listing (often RusticCottageStiches, which also uses PatternFast, or the top-ranking listing for the main keyword). He may send it as a CSV (columns: source, keyword, searches_30d, change, search_results, conversion, median_purchase_price, notes; source = insights / related / suggestion / top_listing).
- For a printable / planner (not a pattern): the final PDF (page list, page count, sizes, digital version). See "Printables and planners" below.

## Round 1: research and the keyword list for the user
0. Check the Keyword bank at the end of this skill first. Reuse any phrase that is there and less than about 3 months old; send to Marketplace Insights only the phrases that are new or stale, so his ~15 weekly searches go to new data.
1. Read the garment facts. Write the core: product noun (e.g. cropped jacket sewing pattern, peplum jacket sewing pattern), the 3 most important details (e.g. collarless, button front, zip front, mandarin collar, ruffle hem, vintage/boucle), audience (women, girls, kids), sizes (00-22 / XXS-4XL, kids 2-16), format (PDF).
2. web searches (all in one go) for competitor Etsy listings and Pinterest/Google wording for this garment: "<garment> sewing pattern etsy", "<garment> pattern pdf women", "<style word> jacket sewing pattern". Note the words that repeat in top titles. A keyword-data page (e.g. makerwords.com/keyword/<phrase>) can give an early listings/shops count; use it only as a hint, never instead of his Marketplace Insights data.
3. Look for the gap: is the style word crowded by another garment type (e.g. "peplum" is full of peplum TOPS, few peplum JACKETS)? Say it in one short line; it guides which phrases to test.
4. Build a seed list and send it to the user in three blocks:
   - **Etsy search bar**: 4-6 short seeds to type into Etsy search (e.g. "cropped jacket pattern", "boucle jacket"); ask him to screenshot the suggestions.
   - **Marketplace Insights**: max 12-15 keywords, ranked by priority (he has about 15 free searches per week, so the most important come first): main product phrases first, then closure/collar/style/fabric phrases, then long-tail, then at most one broad "check" phrase (e.g. peplum top pattern) clearly marked as a demand check. Ask for the searches and listings numbers (screenshot is fine).
   - **eRank**: ask for the tags (and title) of the best competitor listing for the main keyword, and of the matching RusticCottageStiches listing if one exists.
5. Give a provisional title and 13 tags marked DRAFT so he can publish now and update after the data.
6. End with a Sources list of the pages used.

## Round 2: final SEO from the data
Score each keyword: relevance to THIS pattern (must be true), searches (higher is better), listings (lower is better); favor high searches with a good searches-to-listings ratio. Drop keywords that describe something the pattern does not have, and phrases whose searchers are a different audience (e.g. shop owners looking for a size chart for their own products, fitness trackers, parents buying ready-made Christmas pajamas). If the eRank tags did not arrive, finish from the Marketplace Insights and suggestion data and say so in one line.

**Title** (Etsy 2026 guidance: clear, short)
- Under 15 words, about 70-110 characters.
- Start with the product noun phrase with the best data (e.g. "Cropped Jacket Sewing Pattern").
- Then only the 3 most important details (style, closure/neckline, fabric or era), then "for Women", sizes "00-22" (or kids "2-16"), "PDF".
- No filler words (perfect, beautiful, unique, cute), no sale or shipping info, no repeated words, no trademarks (never Chanel or other brand names; use french jacket, boucle jacket, classic jacket).
- Etsy allows each of the characters %, & and : only once in a title: use "&" at most once.

**13 tags**
- Each max 20 characters, multi-word phrases, all 13 used.
- Use the best data phrases that did not fit in the title, the long-tail phrases with few listings, the style/era words (1950s, vintage, retro), fabric words (boucle, tweed, linen), occasion/season (fall jacket, office wear) only if relevant.
- Do not copy competitor tags blindly: keep only the ones that are true for this pattern and have data.
- No duplicates or near-duplicates (singular/plural of the same phrase, zip/zipper, vintage/retro both).
- Never a level tag that is easier than the booklet level (no "beginner sewing" or "easy" for a Confident beginner pattern).
- A good phrase longer than 20 characters is shortened to its strongest part (sewing pattern organizer -> pattern organizer, body measurement chart -> measurement chart, toddler pajama pattern -> toddler pj pattern).

**Attributes** (fill them all: missing attributes lower visibility)
Suggest: category path (Craft Supplies & Tools > Patterns & How To > Sewing & Needlecraft), craft type (Sewing), skill level, garment/style, occasion or season if offered, primary/secondary color if asked (use the photo color). For a planner or printable: category Calendars & Planners, item type Digital, materials PDF / digital file (never Paper), width/height 8.5 x 11 in or empty, undated, occasion if offered; shop section "Planners & Printables".

**Description** (his fixed template with emoji section headings; plain text, "✔" before every list line, one blank line between sections)
Opening (no heading): 3-4 short paragraphs.
- Paragraph 1: one sentence that starts with the main keyword phrase and names the key features (e.g. "Peplum jacket sewing pattern for women with a fitted silhouette, mandarin collar, exposed front zipper and a full circular ruffle at the hem.").
- Paragraph 2: "Create your own <style> <garment> with this printable PDF sewing pattern from SewLuxePatterns."
- Paragraph 3: the construction in words (darts, seams, collar, closure, sleeves, finish).
- Paragraph 4: how to wear or which fabrics make it shine.

Then these sections, in this order, with these headings:
1. 🧵 WHAT YOU WILL RECEIVE: printable PDF pattern; sizes (US 00–22, XXS–4XL, or kids 2–16), one file per size; A4, US Letter, A0 files; complete illustrated step-by-step instructions; body measurement chart and finished garment measurements; fabric requirements; pattern pieces & cutting guide; seam allowance included; helpful video guides; digital download.
2. ✨ DESIGN FEATURES: one ✔ line per real feature, plus the "No ..." lines that prevent wrong expectations (No pockets, No buttons, No lining...).
3. 🪡 SKILL LEVEL: same level and wording as the booklet and cover, plus one or two sentences on which techniques are used.
4. 📏 SIZES: sizes (US 00–22 / XXS–4XL, or kids 2–16 with height and chest range), bust/chest range in cm and in, "choose your size using the body measurement chart included in the sewing instructions" and check the finished measurements.
5. 🧵 SUGGESTED FABRICS (or 🧵 FABRIC): ✔ list of fabrics from the booklet, what to avoid, size-up note for thick fabric, and an IMPORTANT line when the pattern needs a special fabric (e.g. pre-quilted: no instructions for making quilted fabric; pants drafted for stretch knit).
6. 📐 FABRIC REQUIREMENTS: per size group for 150 cm (60") and 115 cm (45"), interfacing/lining, the nap/one-way print note.
7. ✂️ SEAM & HEM ALLOWANCES: every allowance from the pattern (seam, hem, ruffle hem, sleeve hem...).
8. 🧷 NOTIONS: ✔ list with zipper type and lengths per size group, button counts per size, elastic width per size group, interfacing, thread, "Standard sewing supplies"; say where the exact length is given (sewing instructions).
9. 🖨️ PRINTING: files for A4, US Letter, A0; "Print at 100% / Actual Size."; "Do not use Fit to Page, Shrink to Fit or custom scaling."; "Always print and measure the calibration square before printing the complete pattern."
10. 📥 HOW TO DOWNLOAD: TXT file with a Google Drive link; ZIP folders by print format (A4, US Letter, A0), a separate PDF for each size, together with the illustrated sewing instructions.
11. 🎥 HELPFUL VIDEO GUIDES: "The instruction booklet includes optional third-party video tutorials for selected sewing techniques, including:" + ✔ technique names only (no channel names, no links) + "These videos are provided as additional visual help. Always follow the pattern pieces, markings, measurements and construction instructions supplied with this pattern."
12. 🌍 Language Support : always exactly this text, never reworded:
    "The sewing instructions are provided in English.

    If you need translation support for any part of the pattern, please send me a message after purchase. I will be happy to help."
13. 💻 DIGITAL PRODUCT: "This listing is for a digital PDF sewing pattern." + "No physical <garment>, printed pattern, fabric or sewing supplies will be shipped."
14. 💕 CREATE YOUR OWN VERSION: two or three fabric/color ideas, then "Create a unique handmade <garment> while keeping the <key silhouette words> of the original design."
15. Sign-off on two lines: "Happy Sewing ❤️" then "SewLuxePatterns".

## Printables and planners (not sewing patterns)
Same two rounds and the same title/tag rules, with this description instead of sections 2-11 and 14:
- Opening paragraphs: main keyword + page count + what it organises; "Create your own ... with this printable PDF ... from SewLuxePatterns"; what you can do with it; print or digital use.
- 🧵 WHAT YOU WILL RECEIVE (page count, undated, each file format, instant download) · ✨ WHAT'S INSIDE (one ✔ line per section with its page count and page names, totals must add up to the real page count) · 💕 PERFECT FOR · 📏 SIZES & FORMATS · 🖨️ PRINTING (Adobe Acrobat Reader on a computer, not phone/browser; A4 on A4 and Letter on Letter at "Actual size / 100%"; "Fit" on other paper) · 📱 DIGITAL VERSION (apps, tabs, home button, clickable contents, duplicate pages, tablet + app not included) · 📥 HOW TO DOWNLOAD (PDFs delivered directly on Etsy, no ZIP, no extra links, to avoid "can't print" reviews) · 🌍 Language Support with "planner"/"charts" in place of "sewing instructions"/"pattern" (the pattern wording would be false) · 💻 DIGITAL PRODUCT (no physical item shipped, personal use only) · for a smaller product taken from the planner, one "Looking for more?" line pointing to the full planner · sign-off.
- Pricing note: a smaller product cut from the planner should cost clearly less than the planner (about half), and check that Etsy's fixed fees (listing fee + payment processing) still leave a profit after the shop sale.

## Checks before sending
- Every feature, size and number matches the booklet/pattern (or the planner PDF: page names and section page counts add up).
- Skill level is the same in the title/tags/description, the booklet and the cover (if the cover says "Beginner Friendly" but the booklet says Confident beginner, tell him to change the cover: an easier claim than the real level leads to bad reviews).
- No internal generation tools, PatternFast or Tailornova anywhere.
- No trademarks.
- Title under 15 words, "&" at most once; 13 tags each 20 characters or less (count them with code).
- One short line explaining which keywords won and why (with the data numbers).

## After round 2: grow the keyword bank
Every time he sends new data (Etsy suggestions, Marketplace Insights, eRank), add it to the Keyword bank below with the month, then propose the updated skill (full SKILL.md) so the bank grows listing after listing. Keep one row per phrase; when a phrase is measured again, replace its row with the new numbers and date.

### What the data showed (reuse)
- "Typical" conversion phrases are worth more than bigger "low/very low" ones: peplum jacket sewing pattern and mandarin collar jacket pattern.
- Broad phrases (jacket sewing pattern women, vintage jacket sewing pattern) bring searches but huge competition: use them as words in the title or as tags, not as the lead phrase.
- "Zip/zipper" and "ruffle" phrases have almost no searches: describe them in the title and description, but do not spend many tags on them.
- A phrase for another garment type (peplum top pattern) is never used for a jacket, however big its numbers.
- Planners: "sewing planner" leads (most searches, typical conversion); sewing journal, pattern organizer, body measurement chart, sewing planner printable, fabric stash tracker and sewing business all convert very high. "Digital" and "goodnotes" planner phrases have almost no searches: say "Digital" in the title, but do not lead with it. "gift for sewist" has the best ratio before the gift season (low conversion): use it as a tag.
- Measurement charts: "sewing measurement chart" is the best sewing-specific phrase (high conversion, few results), so lead the title with "Sewing Body Measurement Chart". "Size chart" phrases (kids size chart, size chart template) attract shop owners, not sewists: avoid them.
- "sewing tracker" suggestions include excel and google sheets: data for a future spreadsheet listing.
- Kids pajamas: lead the title with "Kids Pajama Sewing Pattern" (covers kids pajama pattern 456 typical + kids pajama sewing pattern 174 very high, few results). Best tags: pajama pants pattern (very high, +66.7%), girls pajama pattern (very high), toddler pj pattern (+128.6%). "Christmas pajamas" phrases are ready-made shoppers (median price $15-18): only as tags, never the lead. "christmas sewing pattern" is stockings/ornaments: avoid. "easy" appears in suggestions but do not use it for a Confident beginner pattern. Sleep sack, onesie and pajama shorts patterns convert very high with few results: ideas for future kids listings.
